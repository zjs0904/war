# ⚔️ 小小大战争 · 双人对战 / 关卡模式

红蓝两军轮流行动的回合制战棋，19×11 随机战场。购买兵种、移动、攻击、占领油田，先摧毁（或占领）敌方基地的一方获胜。每局开战前会自动生成新地图，红蓝两侧地形不完全对称。

- **双人对战**：同一台电脑两人轮流操作
- **关卡模式**：选择第 1–4 关，对战电脑

纯前端，无需安装。

## 运行

直接双击 `index.html` 即可开始。

想在手机 / 局域网里玩，可以在上级目录起个静态服务：

```bash
cd "D:\项目\网页"
python -m http.server 5180
```

然后访问 `http://localhost:5180/war/`；同一局域网内的设备用你的电脑 IP 访问即可。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个 **Public** 仓库（例如 `war-game`），不要初始化 README
2. 在 `war` 目录执行：

```bash
git init -b main
git config user.name "你的名字"
git config user.email "你的邮箱"
git add .
git commit -m "feat: 小小大战争 双人/人机战棋"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

3. 打开仓库 **Settings → Pages**，把 **Build and deployment → Source** 设为 **GitHub Actions**
4. 等 Actions 跑完，链接就是：

```
https://<你的用户名>.github.io/<仓库名>/
```

之后每次 `git push` 自动重新部署。

> 不想用 GitHub 的话，把 `war` 文件夹直接拖到 Netlify Drop，或扔进任意静态服务器目录也能跑。

## 核心规则

- **轮流行动**：红蓝交替，每回合开始获得 **150 金币**，每座油田额外 **+50**。
- **购买**：点击右侧兵种卡片，单位出现在兵营前的生产槽，**当回合即可行动**。
- **生产槽**：兵营前的 3 个 ＋ 格。己方单位在槽上站一回合会回满生命；敌方单位在槽上站一回合会被清除。
- **行动**：点击己方单位选中，绿格移动、红格攻击。每单位每回合可以移动一次并攻击一次，**顺序不限**（可以先攻击再移动）。
- **撤销**：当前回合内可以点击顶部「撤销」或按 **Ctrl+Z** 回退上一步操作（移动、攻击、购买），结束回合后清空。
- **受伤变弱**：单位造成的伤害 = `基础攻击 × 当前生命比例`，残血单位打不出全额伤害。
- **军衔**：击杀达到门槛自动晋升，攻击与生命上限提升，并回复 50% 最大生命（不会回满），避免滚雪球。
- **地形**：每局随机生成，红蓝两侧不镜像。不同地形影响移动消耗与攻防：

  | 地形 | 移动消耗 | 效果 |
  | --- | ---: | --- |
  | 平地 | 1 | 无 |
  | 高地 | 1 | 射程 +2 |
  | 树林 | 2 | 2 格以外的攻击伤害 -25%（贴身不减伤），阻挡远程攻击 |
  | 沼泽 | 2 | 受到的伤害 +20% |
  | 城门 | 1 | 穿过城墙的通道 |
  | 城墙 | — | 无法通行，阻挡远程攻击 |
  | 岩石 | — | 无法通行，阻挡远程攻击 |
- **远程视线**：除手榴弹兵外，所有单位都不能隔着城墙、树林、岩石攻击目标（包括基地）；手榴弹兵曲射不受遮挡影响。
- **油田**：地图上共 6 座，红蓝开局各占 2 座，另有 2 座中立油田（城墙左右各一座，不会只偏袒一边），每座产 50 金币/回合。
- **工程师占领**：
  - 站在敌方或中立油田上，**下一回合开始**自动占领（一个回合）
  - 站在敌方基地旁边，连续 **2 个自己的回合**后占领基地，直接获胜
- **胜利条件**：摧毁敌方基地（1000 生命），或用工程师占领敌方基地。

## 关卡模式

电脑控制蓝方，AI 会：

- 根据局势购买兵种（缺工程师先出工程师、面对多个步兵出手榴弹兵、有钱出突击队员）
- 判断射程与走位，优先击杀残血和高价值目标
- 避开敌方火力覆盖，用工程师去占油田/基地

关卡难度通过电脑的起始金币和每回合额外收入区分：

| 关卡 | 电脑起始金币 | 额外收入 |
| --- | ---: | ---: |
| 第一关 · 新兵 | 300 | 0 |
| 第二关 · 老兵 | 450 | +50 |
| 第三关 · 精英 | 600 | +100 |
| 第四关 · 指挥官 | 800 | +150 |

## 操作

| 操作 | 方式 |
| --- | --- |
| 选择单位 | 点击己方单位 |
| 移动 / 攻击 | 点击绿色 / 红色高亮格 |
| 购买 | 点击右侧兵种卡片 |
| 结束回合 | 点击「结束回合」或按 空格 / 回车 |

| 玩法说明 | 顶部的「?」按钮 |
| 返回菜单 | 顶部的「☰」按钮 |

### 海岛争夺战（v1.21）

主菜单可选择「陆地」或「海岛」，再开始双人对战或电脑关卡。海岛有两侧主岛、中央补给岛、外围小岛、礁石航道及双方造船厂。

| 舰船 | 造价 | 生命 | 攻击 | 射程 | 移动 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| 运输船 | 150 | 220 | — | — | 5 | 搭载 2 名士兵 |
| 高射炮艇 | 300 | 250 | 85 | 4 | 4 | 攻击士兵、舰船及基地，对舰船伤害 70% |
| 鱼雷艇 | 250 | 150 | 180 | 3 | 6 | 仅攻击舰船，不能穿岛发射鱼雷 |

- 上船：选择本回合尚未移动或攻击的士兵，点击相邻己方运输船。
- 登陆：选择运输船，点击相邻金色空陆地，可依次卸下乘员。装卸消耗士兵本回合行动；船可移动后卸载。船沉没时搭载士兵一同损失。
- 中立补给站：任意士兵驻守至己方下回合即可占领。每回合 +75 金币，距离 2 格内友军回复 30 生命；敌军可以重新占领。
- 礁石：舰船移动消耗 2，提供 20% 减伤。己方造船厂每回合修复舰船 40 生命。
- 撤销支持造船、上船、航行、登陆和战斗；电脑支持舰队购买与运输登陆。


### 战术升级（v1.22）

- **控图胜利**：第 3 轮起，陆地两座中立油田或海岛中央补给站，每座在己方回合开始提供 1 分；敌军距离据点 1 格内时不计分。第 12 轮起翻倍，先到 20 分获胜。原有摧毁和占领基地胜利方式继续有效。
- **限时空投**：第 3、7、11……轮在中央区域投放补给，保留 3 轮。部队抵达后立即获得 125 金币并回复 25 生命，舰船也可拾取海上补给。
- **工程师维修**：选择工程师后点击相邻受伤友军，回复 45 生命，消耗本回合攻击机会，仍可移动。可维修舰船。
- **紧急救援**：选择部队后点顶部救援按钮，花费 100 金币，为该部队及相邻友军回复 40 生命，冷却 3 轮。维修、救援和空投拾取均支持撤销。
- **战场信息**：新增回合、双方积分、空投时间和决胜阶段提示。电脑会抢补给、守据点、维修并使用救援。

验证：`node naval.test.cjs`，包含海岛运输与战略玩法回归测试。
